# Awesome-RAG-Orchestration

## Top RAG Orchestration Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**

*Focused on Retrieval-Augmented Generation Pipelines, Document Indexing, Agent Orchestration, Visual Workflow Builders & Production RAG Systems*

**Last updated: August 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **RAG Orchestration**. These tools help developers and teams build, compose, and operate Retrieval-Augmented Generation systems — including document ingestion, indexing, retrieval, reranking, generation, multi-agent workflows, and evaluation.



**Examples** include LlamaIndex, Haystack, Dify, Flowise, LangChain, CrewAI, Dust, TurboML, Rivet, and Fixie (the category leaders).



**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosted RAG frameworks, visual builders, agent orchestration, GraphRAG, and production-ready pipelines — ideal for AI engineers, knowledge platform teams, and organizations seeking full control over retrieval and generation workflows.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[LlamaIndex / LlamaCloud](https://www.llamaindex.ai/)**  

  Leading data framework for LLM applications with deep document parsing, advanced indexing/retrieval, and managed LlamaCloud services for enterprise RAG.



- **[Haystack / deepset Cloud](https://haystack.deepset.ai/)**  

  Production-oriented NLP and RAG framework from deepset, with cloud offerings for building, deploying, and monitoring search and question-answering pipelines.



- **[Dify](https://dify.ai/)**  

  Open-source LLM application platform with visual workflow builder, RAG pipelines, agent support, and hosted cloud options for rapid AI app development.



- **[Flowise](https://flowiseai.com/)**  

  Low-code/no-code visual tool for building LLM orchestration flows and RAG pipelines, available as open-source with commercial hosting options.



- **[LangChain / LangSmith / LangGraph Platform](https://www.langchain.com/)**  

  Comprehensive orchestration ecosystem with LangChain, stateful LangGraph agents, and LangSmith for tracing, evaluation, and production observability (cloud tiers available).



- **[CrewAI](https://www.crewai.com/)**  

  Multi-agent orchestration framework focused on role-based crews and collaborative agent workflows, with open-source core and enterprise offerings.



- **[Dust](https://dust.tt/)**  

  Platform for building custom AI assistants and internal knowledge agents with strong RAG and tool-use capabilities.



- **[TurboML](https://www.turboml.com/)**  

  Real-time machine learning and AI platform that supports streaming and low-latency RAG-style workloads.



- **[Rivet](https://rivet.ironcladapp.com/)**  

  Visual AI programming environment for building and debugging complex LLM workflows and agent graphs.



- **[Fixie](https://www.fixie.ai/)**  

  Platform for building and deploying AI agents with retrieval, tools, and orchestration capabilities.



## Open-Source GitHub Projects

- **[LlamaIndex](https://github.com/run-llama/llama_index)**  

  Premier open-source data framework for building LLM applications with advanced document loaders, indexes, retrievers, and agentic RAG patterns.



- **[LangChain + LangGraph](https://github.com/langchain-ai/langchain)**  

  Widely adopted open-source orchestration library and graph-based runtime for chains, agents, tools, memory, and complex multi-step RAG workflows.



- **[Haystack](https://github.com/deepset-ai/haystack)**  

  Open-source framework for building production-ready NLP and RAG pipelines with modular, serializable components optimized for search and QA.



- **[Dify](https://github.com/langgenius/dify)**  

  Open-source LLM app development platform featuring visual workflows, RAG pipelines, agent orchestration, model management, and self-hosting.



- **[Flowise](https://github.com/FlowiseAI/Flowise)**  

  Open-source low-code tool for visually composing LLM chains, RAG flows, and agent workflows with a drag-and-drop interface.



- **[CrewAI](https://github.com/crewAIInc/crewAI)**  

  Open-source framework for orchestrating role-playing, autonomous AI agents that collaborate on complex tasks including retrieval-augmented workflows.



- **[RAGFlow](https://github.com/infiniflow/ragflow)**  

  Open-source RAG engine focused on deep document understanding, grounded citations, and production-ready knowledge base applications.



- **[DSPy](https://github.com/stanfordnlp/dspy)**  

  Open-source framework from Stanford that treats prompts and RAG pipelines as optimizable programs rather than hand-tuned strings.



- **[Ragna](https://github.com/Quansight/ragna)**  

  Open-source RAG orchestration framework with Python and REST APIs plus a web application for document-based question answering.



- **[LightRAG, ApeRAG, OpenRAG and GraphRAG variants](https://github.com/)**  

  Community and research projects implementing efficient RAG, GraphRAG, multi-modal indexing, and agent-powered retrieval systems.



### Additional Strong Open-Source Options

- **txtai** — All-in-one embeddings database and RAG toolkit.

- **Semantic Kernel** (Microsoft) — Enterprise-oriented orchestration SDK.

- **AutoGen / AG2** — Multi-agent conversation frameworks.

- **Langflow** — Visual builder closely related to the LangChain ecosystem.

- **FastGPT and similar self-hosted knowledge platforms**.

- Evaluation libraries such as **Ragas** for measuring RAG quality.

- Vector database + custom pipeline combinations (Chroma, Qdrant, Weaviate, etc.) orchestrated with minimal frameworks.



**Frameworks for building custom systems**: Choose **LlamaIndex** for document-centric indexing and retrieval, **LangChain/LangGraph** or **CrewAI** for agentic orchestration, **Haystack** for clean production pipelines, or **Dify/Flowise** for visual low-code development. Combine with open vector stores, local embedding models, and self-hosted LLMs (via Ollama, vLLM, etc.). Add **DSPy** for automatic prompt/pipeline optimization and **Ragas** (or similar) for continuous evaluation.

## Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.

- RAG systems process potentially sensitive documents and user queries. Self-hosted open-source stacks require careful attention to data privacy, access control, prompt injection defenses, and evaluation of retrieval quality.

- Framework APIs evolve rapidly; always pin versions and test thoroughly before production use.
